# Noor's Portfolio Glow

I want to build a stunning, modern, and unique personal portfolio website using React, Tailwind Steel, TypeScript, and Lucide React icons. The entire website must be in English and fully responsive.

Please design the website based on the following precise layout, components, color palette, and interactive features:

1. Color Palette & Theme Toggle:

- Use a luxurious color palette inspired by: Deep Burgundy, Dusty Rose, Baby Pink, Ivory, and dark moody slate/charcoal backgrounds for the dark mode.

- Include a fully functional Dark/Light mode toggle switch that smoothly transitions background colors, text tones, and card borders between a deep elegant dark theme and a clean Ivory/Light theme.

2. Header (Navigation):

- Design a floating, semi-transparent glassmorphism navbar inspired by the provided reference image.

- On the left: Display an avatar container with my profile picture placeholder, a glowing neon aura effect around the image, and my name "Noor Abdalfatah" next to it.

- In the center: Navigation links (About, Projects, Skills, Contact) with smooth hover effects.

- On the right: A stylish CTA button (e.g., "Hire Me") with a subtle glowing pulse animation.

3. About Me Section:

- Layout matching the provided About Me reference structure.

- Left side: Section title "About Me" styled with a sleek gradient pill background, followed by an engaging professional bio written for a Full Stack Web Developer and Computer Systems Engineering student, highlighting my passion for building responsive web applications and full-stack solutions.

- Right side: An elegant rounded container placeholder for my personal photo with a soft glowing border and ambient background curves/lines.

4. Projects Section:

- Implement a 3-card sliding carousel layout inspired by the provided project showcase image.

- Each project card features a preview image at the top, a clean title, and a brief description below it.

- Underneath the description on each card, place two buttons:

  1. "Details": Clicking this opens a larger modal/slide-up view displaying more comprehensive information and architecture breakdown about the project.

  2. "GitHub": Direct link pointing to a temporary placeholder GitHub repository.

- Include interactive pagination dots at the bottom of the carousel.

5. Skills Section:

- Create a continuous, infinitely scrolling marquee/slider strip of tech stack icons and badges inspired by the provided image.

- Include skills such as: React, Next.js, TypeScript, JavaScript, Tailwind CSS, PHP, MySQL, Node.js, Python, HTML5, CSS3, Git, and GitHub, styled as sleek dark cards with glowing borders on hover.

6. Contact Me Section:

- Social Media Icons: Direct clickable links (with temporary placeholder URLs) for Instagram, LinkedIn, WhatsApp, GitHub, and Email, styled as interactive glowing icon buttons.

- A dedicated "Download CV" button that links to a temporary resume file.

- Contact Form: Positioned right below the social icons, matching the sleek input fields layout from the reference image (Name input, Email input, Message textarea, and a prominent submit button reading "Send Message" with interactive focus states).

7. Micro-interactions & Animations:

- Add smooth scroll behaviors, fade-in effects on scroll, and delightful hover scaling on cards and buttons.

- Ensure the overall UI looks exceptionally polished, premium, and clean.
